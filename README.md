# 4PDA для Windows 10 Mobile

**Уже реализовано:**
- просмотр новостей
- просмотр форума
- просмотр топиков
- написание комментариев в топиках
- скачивание файлов
- вход в аккаунт
- просмотр чатов в QMS
- написание сообщений в чатах QMS
- живая плитка с новостями

## Приложение использует официальный API, от официального приложения 4PDA
